## 说明
- `boot_mode=check`：只做健康检查，不自动拉起服务。
- `boot_mode=auto`：健康检查失败时执行 `start_cmd` 并等待服务可用。
- `ui_smoke.enabled=true` 且主脚本启用 UI 冒烟时，会调用 `scripts/e2e_ui_smoke_probe.py`。
- `image_upload.enabled=true` 时，runner 会执行真实链路：`/api/upload/detect-type` -> `/api/upload/upload-screenshot` -> 把 OCR 结果放入 `/api/chat.images`。
- 请把原图文件放到上面 `image_upload.images[].path` 对应路径（当前示例为 `artifacts/e2e/real_eval/input_images/`）。
