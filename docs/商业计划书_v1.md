# Crushe 商业计划书

> **让追人这件事，有章可循**

---

## 一、摘要

**Crushe** 是一款 AI 驱动的全生命周期恋爱陪跑服务——恋爱届的 Keep。

我们帮助"想谈恋爱但不会追"的用户，通过「诊断现状 → 制定策略 → 手把手执行 → 反馈迭代」的闭环，真正追到Crush。

**解决方案**：
- 持续诊断：动态构建"你 - Crush - 关系"三维画像，让你看清局势
- 策略制定：基于诊断结果，给出阶段性目标和具体打法
- 手把手执行：每条消息怎么回、朋友圈发什么、约会怎么聊——精细到每一步
- 反馈迭代：根据 Crush 的真实反应持续调整，直到"在一起"

**市场机会**：
- 核心目标用户（18-40 岁、有脱单意愿、因恋爱技能不足而困扰）约 2000-6400 万，基准 3500 万
- 可服务市场规模约 4-22 亿元/年，长期上限可达百亿级
- 现有方案要么太贵（真人咨询 3000-30000 元/次），要么太浅（通用 Chatbot 只能聊天）

**当前阶段**：内测 Demo 开发中，即将启动首批用户验证。

## 二、问题与机会

### 2.1 用户痛点

我们的目标用户是 **"想谈恋爱、有明确心仪对象、但不知道怎么追"** 的人。

典型画像——"兵哥"：
- 某大厂工程师，高学历、高收入、长相不错
- 大学参军，校园与军营生活导致女性接触极少
- 和组内漂亮校招生加了微信，一个月"早安/晚安/在干嘛"的尬聊后，女生回复渐冷
- 误以为是自己对她不够好 → 当众送顶配机械键盘 → 更尴尬

**兵哥的核心问题**：不是条件不好，是 **不懂方法**。

如果没有干预，兵哥面临的结局：
- 盲目发力 → 女生压力爆棚 → 失败
- 自我否定 → 觉得配不上 → 主动放弃
- 归咎对方 → "我对你这么好还不理我" → 愤而放弃

**这不是个例。** 中国有近 3 亿单身人口，其中相当比例是"想谈但不会谈"。

### 2.2 现有方案的不足

| 方案 | 问题 |
|:----|:----|
| **真人情感咨询**（花镇、小鹿情感） | 贵（3000-30000 元/次）、服务不标准、行业乱象多 |
| **通用 Chatbot**（豆包、千问等） | 缺乏恋爱领域 know-how，无法持续追踪上下文，给出的建议泛泛而谈，最终解决"在一起"这个目标的效果差 |
| **高情商键盘/话术工具** | 只解决"这句话怎么回"，没有全局策略 |
| **朋友/网友建议** | 不专业、主观、容易误导 |

**市场空白**：没有一个产品围绕"帮用户追到 crush"这件事，做全生命周期的拆解和陪跑。

### 2.3 市场规模

**目标用户规模**

我们的核心用户是：18-40 岁单身、有脱单意愿、且以恋爱技能不足为主要障碍的人群。

| 情景 | 用户规模 |
|:----|:--------|
| 保守 | 2030 万 |
| 基准 | 3490 万 |
| 乐观 | 6390 万 |

*测算依据：单身成年人 2.4 亿量级（民政部/央视）× 适龄占比 × 脱单意愿占比 × 技能问题占比*

**市场规模（年收入口径）**

| 情景 | 市场规模 | 假设条件 |
|:----|:--------|:--------|
| 保守 | 3.9 亿元/年 | 付费率 8%，ARPPU 240 元/年 |
| 基准 | 22 亿元/年 | 付费率 15%，ARPPU 420 元/年 |
| 乐观 | 128 亿元/年 | 付费率 25%，ARPPU 800 元/年 |

**外部校验**：2023 年互联网婚恋交友行业规模约 93.8 亿元（艾媒咨询），我们的基准估计约为其 23%，属于合理的细分赛道规模。

**为什么这个需求是真实的**

调研数据显示（《下沉市场青年单身与交往报告》，n=3617）：
- "社恐、自卑、价值感低"是脱单最大困境，占 34.86%
- "不会沟通/沟通不良"是分手首要原因，占 32.38%
- 63.77% 的单身青年明确"想脱单"
- 超过 7 成愿意为脱单支出

这些障碍（社交能力、沟通技巧、心理建设）恰好是 AI 可以通过陪练、复盘、话术优化、情景模拟来解决的。

## 三、产品与解决方案

### 3.1 产品定位

**Crushe = 恋爱届的 Keep**

Keep 帮用户"练出好身材"：制定计划 → 跟练课程 → 记录反馈 → 持续迭代
Crushe 帮用户"追到心仪对象"：诊断现状 → 制定策略 → 手把手执行 → 反馈迭代

### 3.2 核心功能

我们把"追人"这件事拆解成一个可量化、可执行的闭环：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   模块一：持续诊断 —— 构建用户、Crush、关系的三维全景                          │
│   ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│   这不是一次性的"出报告"，而是持续、动态地构建对三个维度的全面了解：            │
│                                                                             │
│   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐                    │
│   │   用户画像   │    │  Crush 画像  │    │   关系现状   │                    │
│   │  性格/价值观 │    │  性格/喜好   │    │  ACR 评分   │                    │
│   │  优势/短板  │    │  雷区/加分项 │    │  L/T 阶段   │                    │
│   │  社交风格   │    │  沟通偏好    │    │  核心阻力   │                    │
│   └─────────────┘    └─────────────┘    └─────────────┘                    │
│                                                                             │
│   信息获取方式：                                                             │
│   • 对话中自然收集（聊天记录分析、用户描述）                                   │
│   • 主动引导测试（性格测试、情景问答）                                        │
│   • 关键事件触发更新（聊天截图、约会反馈）                                     │
│                                                                             │
│   核心价值：                                                                 │
│   • 为模型决策提供充分上下文，提高策略精准度                                   │
│   • 以可视化形式呈现（情感罗盘、关系地图），让用户"看清局势"                    │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   模块二：策略制定与手把手执行                                                │
│   ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│   基于最新的诊断结果，为用户制定最佳策略并手把手教用户达成。                     │
│                                                                             │
│   【策略层】                                                                 │
│   • 阶段性目标：冷冻期 → 重建期 → 推进期 → 确立期                             │
│   • 里程碑设定：对方主动开启话题、接受单独邀约、确立关系...                     │
│   • 打法原则：当前阶段该做什么、不该做什么                                     │
│                                                                             │
│   【执行层】                                                                 │
│   • 任务执行计划：每日/每周具体任务卡片，明确步骤和预期结果                     │
│   • 聊天应对系统：                                                           │
│     - 消息回复建议（不只是"怎么回"，而是"为什么这样回"）                       │
│     - 对话走向预测（她可能怎么回应，你该如何接招）                             │
│     - 聊天节奏把控（什么时候该聊、该停、该升温）                               │
│   • 朋友圈指导：发什么内容、什么时间发、配什么文案                             │
│   • 线下约会陪练：约会前的 AI 模拟对练，预演可能场景                           │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   模块三：反馈迭代 —— 基于真实反馈持续优化                                     │
│   ───────────────────────────────────────────────────────────────────────   │
│                                                                             │
│   • 用户反馈：任务执行结果、聊天截图、约会复盘                                 │
│   • Crush 反馈：对方的回应变化、态度信号                                      │
│   • 系统响应：                                                               │
│     - 正常推进 → 生成下一个任务                                              │
│     - 里程碑达成 → 进入下一阶段                                              │
│     - 出现异常 → 重新诊断、调整策略                                          │
│                                                                             │
│   循环：诊断 → 策略 → 执行 → 反馈 → 诊断...                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.3 AI 人格："小话"

用户感知到的始终是"小话"一个角色——一个有血有肉的恋爱军师：
- 既能陪你吐槽
- 也能帮你出谋划策
- 还能手把手教你怎么做

背后是多 Agent 协作架构，但对用户完全透明。

### 3.4 差异化优势

| 维度 | 传统情感咨询 | 通用 Chatbot | Crushe |
|:----|:-----------|:----------|:-------|
| 价格 | 3000-30000 元/次 | 免费或低价订阅 | 中等价位 |
| 可用性 | 预约制，响应慢 | 7×24 小时 | 7×24 小时 |
| 服务深度 | 深但不标准 | 浅，缺乏领域 know-how | 深且标准化 |
| 结果导向 | 弱 | 无 | 强（追到为目标） |
| 上下文理解 | 依赖咨询师记忆 | 单次对话，无持续追踪 | 全生命周期追踪 |
| 执行指导 | 有但粗糙 | 泛泛建议 | 精细到每一步 |
| 可复制性 | 低（依赖个人） | 高 | 高 |

## 四、商业模式

### 4.1 收费模式

**主模式：按 Crush 付费**
- 用户为每一个"追人项目"付费
- 价格区间：待内测验证（参考：99-299 元/crush）
- 优势：结果导向，用户付费意愿强

**辅助模式：订阅制**
- 月度/年度会员
- 适合多 crush 用户或长期情感陪伴需求

### 4.2 单位经济模型（假设）

| 指标 | 保守估计 | 基准估计 | 乐观估计 |
|:----|:--------|:--------|:--------|
| 客单价 | 99 元 | 199 元 | 299 元 |
| 付费转化率 | 3% | 5% | 8% |
| 月活用户 | 10 万 | 50 万 | 100 万 |
| 月收入 | 29.7 万 | 497.5 万 | 2392 万 |

*注：以上为假设数据，需内测验证*

### 4.3 增长路径：从"追到"到"陪伴"

短期内我们聚焦"帮用户追到 crush"这一件事。

但这不是终点——**用户追到 crush 后"流失"，换来的是信任。**

基于这份信任，我们可以拓展：
1. **在一起后**：长期情感指导（如何维护关系、如何处理矛盾）
2. **分手后**：重新瞄准新 crush，或情感修复
3. **空窗期**：纯情感陪伴

**本质上，Crushe 不是一个用完即走的工具，而是一段"关系"、一种"羁绊"。**

用户和"小话"一起经历了追人的全过程，这种陪伴会转化为长期信任和品牌忠诚。

## 五、竞争分析

### 5.1 竞争格局

**第一类：传统情感咨询（花镇、小鹿情感等）**

| 优势 | 劣势 |
|:----|:----|
| 真人服务，深度高 | 价格贵（3000-30000 元） |
| 有成熟方法论 | 服务不标准，依赖个人 |
| | 行业乱象多，信任度低 |
| | 响应慢，需预约 |

**我们的差异化**：AI 提供 7×24 小时服务，价格更低，服务标准化。

**第二类：通用 Chatbot（豆包、千问等）**

| 优势 | 劣势 |
|:----|:----|
| 7×24 小时在线 | 缺乏恋爱领域专业 know-how |
| 价格低或免费 | 无法持续追踪用户上下文和关系进展 |
| 通用能力强 | 给出的建议泛泛而谈，缺乏针对性 |
| | 不以"在一起"为目标，无法衡量效果 |

**我们的差异化**：垂直领域深耕，全生命周期上下文追踪，以"追到"为明确目标。

**第三类：AI 情感陪伴（Character AI、星野等）**

| 优势 | 劣势 |
|:----|:----|
| 7×24 小时在线 | 定位是"陪伴"而非"解决问题" |
| 用户粘性高 | 没有行动指导和执行层面的帮助 |
| | 不以现实中的"结果"为导向 |

**我们的差异化**：不是虚拟陪伴，而是帮用户在现实中追到真实的人。

**第三类：工具类产品（高情商键盘等）**

| 优势 | 劣势 |
|:----|:----|
| 解决即时问题 | 只能解决"这句话怎么回" |
| 使用门槛低 | 没有全局策略 |
| | 不理解用户具体情况 |

**我们的差异化**：全生命周期陪跑，不是单点工具。

### 5.2 竞争壁垒

1. **方法论壁垒**：我们对"追人"这件事做了系统性拆解（ACR 模型、L/T 阶段、任务卡片体系），这套方法论需要时间积累和验证

2. **数据壁垒**：随着用户量增长，我们会积累大量"追人成功/失败"的案例数据，用于优化模型和策略

3. **信任壁垒**：用户和"小话"建立的情感连接，是竞品难以复制的

## 附录：核心概念说明

### ACR 情感物理学

用于评估关系健康度的三个维度：

| 维度 | 全称 | 含义 |
|:----|:----|:----|
| **A** | Attraction（吸引力） | 硬价值与繁衍价值 |
| **C** | Comfort（舒适感） | 安全感与信任 |
| **R** | Romance（张力） | 暧昧博弈与不可得性 |

### L/T 关系坐标系

**L 线（主线）**：ACR 均衡同步上涨
- L1 初识期 → L2 吸引期 → L3 暧昧期 → L4 确立期

**T 线（陷阱线）**：要素缺失或比例畸形
- T1 备胎/供养者：C >>> A
- T2 兄弟/死党：C 覆盖了 R
- T3 短择/炮友：R > C
