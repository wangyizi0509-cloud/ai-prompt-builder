Ask Human Tool Result 展示 Demo

同一份 tool result，演示 5 种前端呈现。可上方筛选单看某一种。

方案 1: 用户气泡 + Tool 徽标

聊天感强 / 语义中等
AI
我需要你补充几个背景信息，便于给你更准确建议。
ASK_HUMAN_RESULT
认识 3 个月，同事介绍。最近聊天忽冷忽热，我想确认该不该继续推进。
目标：判断是否继续追
近期互动：忽冷忽热
关系来源：同事介绍
来自表单提交 · tool result
AI
收到，我会先给你一个低风险试探策略。

方案 2: 独立结果卡（推荐）

语义清晰 / 审计友好
AI
请填写你的情况，我会按你填写的内容继续分析。
用户填写结果 tool result
出生年份：1995
认识时长：3个月
当前问题：对方回复节奏不稳定
你想要的结果：判断是否继续推进关系
request_id: ask_human_20260212_001
AI
我会分成「继续推进」和「止损退出」两条路径给你建议。

方案 3: 时间轴步骤卡

流程最清楚 / UI 成本高
Step 1: AI 发起信息采集（ask_human）
Step 2: 用户填写并提交问卷（4 项）
Step 3: 系统接收 tool result
关系阶段：认识期
主要矛盾：互动不稳定
诉求：是否继续
Step 4: AI 生成下一步策略

方案 4: 对话气泡 + 折叠回执

联动演示: 卡片 -> 填写 -> 回执
AI
我发了一个信息补充卡片，填完后会自动生成回执并继续分析。
AI
收到补充信息，我会按你的背景继续输出下一步策略。
联动逻辑: 任务卡片与回执共用同一 taskKey，提交后点卡片会定位并展开回执。

填写补充信息

taskKey: ask_human_task_001
请先完整填写全部字段。

方案 5: 系统事件条 + 引用块

系统感强 / 边界清晰
系统事件：用户已完成填写（ask_human）
出生：1995 | 认识时长：3个月 | 关系来源：同事介绍
诉求：最近聊天忽冷忽热，想判断是否继续推进
AI
收到，下面给你一个「继续推进」的低风险行动方案。
