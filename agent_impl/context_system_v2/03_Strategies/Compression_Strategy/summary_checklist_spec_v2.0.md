# 摘要质量标准（Summary Checklist Spec v2.0）

> 目的：让不同场景（对话/报告/规划/指南/任务推理）的摘要产出风格一致、信息密度一致、可用于决策，而不是“流水账”。

---

## 1. 通用原则（任何摘要都适用）

### 1.1 三个标准

- **信息密度高**：每句话都有决策价值
- **可操作**：读完就知道下一步该怎么做/该注意什么
- **可追溯**：关键结论能追溯到证据或事实来源

### 1.2 字数建议（经验范围）

| 摘要类型 | 建议长度 | 说明 |
|:---|:---|:---|
| 中等摘要（summary） | 100–200 字 | 结论 + 关键证据 + 待办 |
| 一句话摘要（one_liner） | 20–30 字 | 只保留结果/结论 |
| 对话摘要（ConversationSummary.summary） | 150–300 字 | 互动质量 + 关系动态 + 新信息 + 待办 |

---

## 2. 对话摘要检查清单

确保包含：
- [ ] **核心话题**：这段对话主要聊了什么（1–2 个主题）
- [ ] **关系动态**：互动质量有没有变化（升温/降温/试探/拒绝）
- [ ] **新事实**：出现了哪些新的客观信息或约定（如果有）
- [ ] **关键结论**：当前最重要判断是什么（如果形成了）
- [ ] **待办**：下一步要做什么/要问什么（如果有）

避免包含：
- 寒暄/客套话
- 逐句复述（流水账）
- AI 的长篇输出（只保留结论与关键建议）

---

## 3. 现状报告摘要检查清单

确保包含：
- [ ] **阶段判定**：当时处于什么阶段（如 L2/T1 等）
- [ ] **核心问题**：主要阻碍/风险点是什么
- [ ] **态势判断**：对方态度/动力方向如何
- [ ] **关键发现**：最重要证据/洞察是什么
- [ ] **建议方向**：一句话概括策略方向

避免包含：
- 过多细节字段（评分细则、长表格）
- 重复 Layer 1 已有的人物基础信息

---

## 4. 行动规划摘要检查清单

确保包含：
- [ ] **阶段目标**：要达成什么
- [ ] **核心策略**：大方向是什么（降压/升温/扩展接触等）
- [ ] **关键里程碑**：推进节点与成功标准
- [ ] **约束条件**：必须避免的坑（例如对方忙/用户执行力有限）

避免包含：
- 过细的每日安排（应在行动指南或当轮对话中体现）

---

## 5. 行动指南摘要检查清单

确保包含：
- [ ] **任务概述**：这条指南要做什么
- [ ] **执行情况**：用户是否执行、怎么执行
- [ ] **用户反馈**：用户的原话关键词（非常有价值）
- [ ] **对方反应**：对方做了什么（最好落到 fact）
- [ ] **关键收获**：沉淀到 Layer 1/2 的稳定结论是什么

避免包含：
- 冗长的原指南正文（正文本体可用工具按需加载）

---

## 6. 任务推理摘要（Rolling Scratchpad Summary）

当推理笔记过多需要压缩时，摘要应保留：
- [ ] 关键决策点（做了哪些选择）
- [ ] 排除的假设（哪些可能性被证伪）
- [ ] 当前进度（处于哪一步）
- [ ] 下一步方向（还需要什么信息/动作）
