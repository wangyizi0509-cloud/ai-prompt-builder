## 目录约定

`agent_impl/frontend/assets/onboarding/` 下放所有「题后钩子」里引用到的产品功能预览图。

钩子 JSON 里只写相对路径（比如 `assets/onboarding/局势分析.png`），前端在渲染 `<img>` 的 `src` 时会自动回落到同目录下的 `placeholder.svg`，以便设计师未交付时不出现 404。

## 需要设计师最终交付的 5 张图（PNG/JPG 均可，建议 PNG）

| 文件名 | 对应功能（用在哪里） |
| :--- | :--- |
| `局势分析.png` | Q3/Q4 相关钩子，展示 ACR 雷达 + 5 维评分卡样例 |
| `行动规划.png` | 表白后 + 高投入组合钩子，展示 Phase 1-3 阶段计划 |
| `聊天指导.png` | 冷淡/敷衍组合，展示逐条消息批注与话术建议 |
| `行动指南.png` | 邀约被拒场景，展示时机+理由+话术+成功率预估 |
| `朋友圈指导.png` | 工具人化钩子，展示本周朋友圈建设计划 |

## 交付规范（建议）

- 宽度：375-750px（2x），高度 ≤ 600px
- 色调：沿用诊所风主色 #8A4BFF + #FF65C2
- 留白：图片内外部都留一点边距，避免贴边

## 占位 SVG

当前使用 `placeholder.svg` 作为兜底。前端在加载具体图片失败时会自动切换到该 SVG，不会报错。替换交付图之后可以保留或删除 `placeholder.svg`，不影响主流程。
