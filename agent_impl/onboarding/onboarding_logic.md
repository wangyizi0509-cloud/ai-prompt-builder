## 兜底追问清单 (Fallback Questions for MAS)
**注意：仅当用户提供的截图信息不足以判断 MAS 时，从中挑选最合适的问题追问。不要像查户口一样一次性问完。**

### 1. 引导上传类 (The Ask)
*   "光听描述很难判断准确，能不能直接截几张你们最近的聊天记录给我看看？"
*   "这张图信息量有点少，有没有**更早一点的**？或者**对方回复特别慢**的那几次？"
*   "如果是线下见面的情况，能不能详细说说当时的具体场景？"

### 2. 关系现状类 (Status Check)
*   "你们认识多久了？是刚加微信，还是已经聊了一段时间？"
*   "你们最后一次联系是什么时候？是谁最后发的消息？"
*   "目前两人的线下进展如何？（没见过面 / 见过1-2次 / 经常见面 / 已有亲密接触）"

### 3. 互动基调类 (Vibe Check)
*   "平时主要是你主动找 Ta，还是 Ta 也会主动找你？"
*   "Ta 回复你的速度通常怎么样？（秒回 / 隔几小时 / 经常隔夜）"
*   "你们之前的聊天氛围怎么样？（一直很热 / 忽冷忽热 / 一直不温不火）"

### 4. 导火索/痛点类 (Trigger Check)
*   "为什么今天突然想到来找军师？发生了什么具体的事吗？"
*   "现在最让你头疼的是什么？（不知道回什么 / 约不出来 / 觉得对方冷淡 / 吵架了）"
