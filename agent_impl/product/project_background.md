# Crushe AI产品项目背景介绍 (Project Background)

## 1. 目标用户 (Target User)

根据对 C 端用户（如小红书用户）的洞察，我们的核心用户主要分为两类。虽然这两类用户可能互相转化，但在同一时间点，用户通常只属于其中一种。

**我们产品的核心聚焦于解决「明确者」的问题。**

### 1.1 用户分类

1.  **明确者 (The Determined)**
    *   **特征**：对 Crush 有明确兴趣。
    *   **判断标准**：如果对方现在立马愿意跟他在一起，他会毫不犹豫地同意。
    *   **核心问题**：**"如何才能跟对方在一起？"**（目标：谈一场甜甜的恋爱）。

2.  **摇摆者 (The Hesitant)**
    *   **特征**：对 Crush 兴趣不明确，需要在持续接触中判断。
    *   **判断标准**：如果对方立马愿意跟他在一起，他反而会选择拒绝或犹豫。
    *   **核心问题**：
        *   "我是否应该继续？"（考量对方心意、成功率、人品等）。
        *   "如果值得/不值得，我应该如何做？"。

## 2. 典型画像 (User Persona)

### 2.1 待开窍的帅哥 —— “兵哥”
> **“代码我能懂，但她我不懂”**

#### A. 基础信息
*   **姓名**：兵哥
*   **性别**：男
*   **职业**：某大厂工程师
*   **背景**：大学参军，校园与军营生活导致女性接触极少。毕业后在大厂工作 3 年，生活轨迹单一（家-公司-偶尔摄影）。
*   **优势**：高学历、高收入、长相不错（硬性条件优越）。

#### B. 用户故事 (User Story)
兵哥最近加上了组内漂亮校招生的微信。起初女生热情主动，但经历了一个月“早安/晚安/在干嘛”的无营养尬聊后，女生回复渐冷。
兵哥误以为是自己对她不够好，开始盲目发力挽回，当众送出自己最爱的顶配机械键盘，结果局面尴尬，聊天更僵。

#### C. 当前困境与心理
此刻的兵哥认为：**喜欢 = 疯狂粘人 + 无限对她好**。但实操发现对方反而更冷淡，完全想不通原因。
如果缺乏外部干预，兵哥面临的结局通常是 **BE (Bad Ending)**：
1.  **盲目发力**：觉得自己还是不够好 -> 发力更狠 -> 女生压力爆棚厌烦 -> 兵哥迷茫 -> BE。
2.  **自我否定**：觉得自己配不上对方 -> 主动放弃 -> BE。
3.  **归咎对方**：觉得对方是海王/渣女 -> "我对你这么好还不理我" -> 愤而放弃 -> BE。

## 3. 核心问题拆解 (Core Problem Analysis)

我们将“如何跟谈一场甜甜的恋爱”本质上看作是一个 **销售转化率优化问题**。

### 3.1 失败原因分析
通常只有两个原因：
1.  **营销没做好 (Marketing Fail)**：他没发现你的好（兵哥现状）。
2.  **PMF 没做好 (Product-Market Fit Fail)**：你根本不是他的菜（匹配度问题）。

### 3.2 我们的策略
不同于商业销售可以“换产品”或“换市场”，在恋爱场景中：
*   **产品不可换**：产品就是用户自己。
*   **市场难替换**：情感具有排他性，换个 Crush 成本极高。

因此，我们的策略是：
*   **优先做营销**：作为小白销售员（用户）背后的 **“销售总监”**，教他如何正确展示高价值，优化互动技巧。
*   **PMF 验证作为风控**：在过程中通过 AI 分析双方匹配度。如果极大概率不匹配，作为“风险预警”提示用户，避免无谓投入。我们用“短期留存”（强行劝用户追求）来换取用户的长期信任。

## 5. 解决方案 (Solution)

采用 **“Owner-Expert” (责任人-专家)** 的多Agent协同架构，模拟真实的高效决策团队：

*   **业务负责人 (Owner / Main Agent)**：
    *   **核心定位**：用户目标的**终极责任人**。他的目标永远与用户最终目标保持一致（例如：“跟 Crush 在一起”）。
    *   **职责与权限**：
        *   **最高决策权**：全权决定何时引入专家、引入哪位专家、或使用何种技能。
        *   **策略优化**：基于用户反馈和实际效果，动态调整决策策略，持续提升目标达成的概率。
*   **专家支持团队 (Expert Support Team)**：
    *   **Status Agent (分析师)**：提供客观冷峻的局势诊断（“现在是什么情况”）。
    *   **Plan Agent (战略家)**：提供宏观的战役规划（“大方向该怎么走”）。
    *   **Guide Agent (教练)**：提供具体的战术落地（“这步具体怎么做”）。

## 6. 功能概览 (Feature Overview)

1.  **智能诊断**：自动生成《情感罗盘报告》，量化关系状态，识别致命伤。
2.  **战略导航**：定制化的《行动规划书》，明确下一阶段目标与打法。
3.  **手把手教学**：场景化的《任务执行卡》（如：聊天回复建议、朋友圈建设指南）。
4.  **实时陪跑**：7x24 小时在线，随时解答情感疑惑，提供情绪疏导。
5.  **交互创新**：
    *   **提问卡 (Inquiry Card)**：引导用户高效输入关键信息。
    *   **任务卡 (Task Card)**：结构化呈现执行步骤，便于跟进状态。
