# 截图类型识别

分析图片，判断属于以下哪种类型。按顺序判断，符合就停止：

## 1. 先判断是否为「对话界面」

对话界面的特征：
- 有消息气泡（左右分布或上下排列）
- 有输入框或发送按钮
- 消息有时间戳
- 整体是聊天软件的界面风格（微信、QQ、iMessage、WhatsApp 等）

**如果是对话界面，继续判断私聊还是群聊：**

### private_chat_screenshot（私聊）
判断标准：对话界面 + 只有两方参与
- 左侧消息只有一个发送者（一个头像或一个名字，或都没有但明显是同一人）
- 右侧是用户自己发的消息
- **不要求**必须有头像或昵称，只要看不出有多人即可

### group_chat_screenshot（群聊）
判断标准：对话界面 + 能看出有多人参与
- 左侧消息有多个不同的头像，或
- 左侧消息有多个不同的名字/昵称，或
- 有群名称显示，或
- 其他明显的多人聊天特征

## 2. 如果不是对话界面，继续判断：

### moments_screenshot（朋友圈）
- 微信朋友圈界面
- 有发布者头像、动态内容、点赞评论区
- 瀑布流式的动态列表

### other_social_media_screenshot（其他社媒）
- 小红书、Instagram、微博、抖音、Twitter/X 等平台
- 帖子、笔记、动态、评论区等内容展示界面
- 非对话形式的社交媒体内容

### universal_screenshot_analysis（通用/其他）
- 不属于以上任何类型
- 个人主页、设置页、通讯录、通知列表等
- 无法确定类型

## 输出格式

严格按以下 JSON 格式返回，不要有其他内容：

{"type":"类型名称"}
