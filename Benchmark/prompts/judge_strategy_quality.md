## 评分规则

- 分数范围：1.0 - 5.0（可使用 0.5 步长）
- 3.0 分 = 勉强及格，能完成任务但建议太通用
- 3.5 分 = 基本合格，有一定针对性，可以接受
- 4.0 分 = 良好，策略具体且有针对性，能直接拿去用
- 4.5 分 = 很好，充分利用了用户/crush 的个人信息，有深度
- 5.0 分 = 优秀，策略精准、有温度、体现了对用户情况的深刻理解

## 严重扣分情形（直接 ≤ 2.0 分）

以下任意一条出现，最终分数不超过 2.0 分：

1. AI 给出了完全通用的建议，对话中有用户/crush 的具体信息但完全没有用到
2. AI 建议用户做某个行动，并预测了 crush 会如何反应，但完全是无依据的猜测
3. AI 的回复与用户的问题完全不相关，转移了话题
4. AI 给出的建议是明显错误的或有害的（如建议用户撒谎、撒气等）

## 输出格式

必须严格按照以下 JSON 格式输出，不要有任何其他文字：

```json
{
  "score": 4.0,
  "pass": true,
  "reasoning": "一句话说明为什么给这个分数（说明最关键的得分/扣分原因）",
  "issues": ["具体问题描述，如果没有问题则为空数组 []"]
}
```

说明：
- `pass` = `score >= 3.5`
- `reasoning` 不超过 50 字，聚焦在最关键的一点
- `issues` 列出所有具体问题，每条 20-40 字
